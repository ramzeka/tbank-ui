## Изменения конфигурации

Адрес сервера и префиксы маршрутов задаются в конфигурации запуска. Для STAGE с префиксом шлюза подойдёт следующая настройка.

```ini
stage=https://stage.proxy.example.org/gateway
stage.prefix=/api/v1/nominal-accounts
```

`stage.prefix` можно опустить при стандартном пути. После редактирования `proxy.cfg` перезапустите приложение. В интерфейсе остаются выбор окружения и параметры счёта. Для обновления профиля, в котором по прежнему маршруту остались незавершённые операции, сверка этих операций на шлюзе требуется перед очисткой соответствующих ключей в браузере. [Шаблон конфигурации](../proxy.example.cfg)
