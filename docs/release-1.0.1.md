# Т-Банк UI 1.0.1

25 ноября 2026 года.

## Изменения с 1.0.0

- Вкладка **Поддержка** заменила «Операционный контроль» и открывается первой. В ней видны сумма неидентифицированных пополнений, общее количество из ответа банка и разбивка по датам МСК. Кнопка **К пополнениям** открывает первую страницу из тех же данных. После идентификации сводка обновляется при следующем открытии.
- Обзор «Поддержки» загружает до 50 записей одним запросом. При более длинном списке сумма и разбивка относятся к загруженным записям, а интерфейс сообщает о неполной выборке.
- Во вкладке **Деньги и операции** остались график движения денег, суммы поступлений и списаний и последние проведённые операции. За 7 или 30 календарных дней загружается одна выписка с `limit=5000`. При наличии курсора интерфейс помечает показатели как частичные.
- Выписка учитывает настроенный путь шлюза и стандартные префиксы номинальных счетов с сегментом `/api` и без него. Запрос передаёт `bankAccountId`, если он задан в настройках подключения.
- Для DEV, STAGE и PROD используется один файл [proxy.cfg](../proxy.cfg). Настройки номера и идентификатора счёта сохраняются отдельно для каждого окружения.

## Подключение

Настройте HTTPS-адрес и префикс прокси в `proxy.cfg`, затем запустите `start.cmd`. В интерфейсе выберите окружение, сохраните параметры счёта и войдите с Bearer-токеном. Для пополнений и выписки используются соответствующие права T‑API. [Инструкция, пример конфигурации и права токена](../README.md#подключение-и-данные)

## Проверка

| Команда | Результат |
| --- | --- |
| `node tests/qa/run.mjs` | **58 из 58**, включая 47 задокументированных HTTP-операций и 9 проверок безопасности |
| `node tests/qa/run.mjs --scale` | **3 из 3** на 50 000 бенефициаров, 20 000 пополнений и 20 000 платежей |

`DASH-01` проверяет группировку на границе суток МСК, точную сумму до копейки, частичный ответ, переход в «Пополнения» без повторного запроса и один запрос выписки на период. `AUTH-04` проверяет передачу `bankAccountId` при запросе выписки через путь шлюза. `RELAY-02` проверяет выбор маршрутов выписки для настроенных префиксов.

Прогоны выполнены в Windows, на Node.js 24 и Microsoft Edge с отдельным тестовым профилем. Данные на всех 11 скриншотах синтетические. Банковский шлюз в прогонах не использовался. [Запуск и покрытие автотестов](../tests/qa/README.md)
